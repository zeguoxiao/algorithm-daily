# Algorithm Daily

LeetCode 刷题记录，按题号归档。

## 目录结构

```
algorithm-daily/
├── README.md
├── LeetCode/
│   ├── 0001/
│   │   ├── README.md      ← 题目 + 思路笔记
│   │   └── solution.py    ← 代码
│   ├── 0002/
│   │   ├── README.md
│   │   └── solution.java
│   └── ...
```

## 使用方法

1. 在 `LeetCode/` 下新建文件夹，命名为题号（如 `0001`）
2. 把代码粘贴到 `solution.java`（或其他语言后缀）
3. 在 `README.md` 里写笔记：思路、复杂度、踩坑记录

不积跬步无以至千里，不积小流无以成江海！！！
